# MRHead Projection Demo

This folder contains example outputs generated from the `MRHead.nrrd` medical imaging volume.

## Files

- `MRHead_sagittal_sweep.csv` — The plane coordinates used to generate the projection sequence.
- `MRHead_sagittal_sweep_native.mp4` — The original video generated by the project.
- `MRHead_visualization.mp4` — An enhanced version for easier visual inspection, if applicable.
- `MRHead_single_plane.mp4` — An example of a projection using a single plane, if included.

## How It Was Generated

The project reads the NRRD volume and the plane coordinates from the CSV file, projects each plane into a 2D image, and combines the resulting frames into an MP4 video.

Run the following command from the project root:

```bash
python Ex0.py data/MRHead.nrrd results/MRHead_demo/MRHead_sagittal_sweep.csv results/MRHead_demo/MRHead_sagittal_sweep_native.mp4
```

The output contains one frame for each plane in the CSV file. The enhanced visualization, if included, is provided for presentation purposes and is not the original program output.
