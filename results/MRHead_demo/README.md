# MRHead Projection Demo

This folder contains a video generated from the `MRHead.nrrd` medical imaging volume using the project's 3D-to-2D projection algorithm.

## Files

- `head_mri_side_scan.csv` — Contains the coordinates of 81 projection planes.
- `head_mri_side_video.mp4` — The MP4 video generated by the project.

## How It Works

The program loads the 3D MRI volume and reads the plane coordinates from the CSV file. It projects each plane onto a 2D image and combines the resulting images into a video.

Each video frame corresponds to one plane from the CSV file, in the same order.

## How to Reproduce the Video

Run the following command from the project root directory:

```bash
python Ex0.py data/MRHead.nrrd results/MRHead_demo/head_mri_side_scan.csv results/MRHead_demo/head_mri_side_video.mp4
```

The command generates the MP4 output using the project's original projection and video-writing code.
